\# Day 1 - Ubuntu Wazuh Server Base



\## Done

\- Created project folder structure.

\- Installed Ubuntu Server 24.04.4 LTS in VMware.

\- Assigned 8 GB RAM, 4 CPU cores, 80 GB disk, NAT networking.

\- Enabled OpenSSH.

\- Confirmed hostname, IP address, memory, and disk space.

\- Expanded root disk to about 77 GB.

\- Updated Ubuntu and installed basic tools.

\- Took VMware snapshot: Clean Ubuntu Server Base.



\## Learned

\- The Wazuh server needs a stable Ubuntu base before installing Wazuh.

\- VMware disk size and Linux usable root space can be different until LVM is expanded.

\- NAT networking gives the VM a private lab IP.
